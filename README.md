# 🎓 EduControl & Campus Pro v1.0 — ERP Académico, Colegiaturas, Solvencias QR & Actas MINEDUC

**Propietario y Desarrollador Principal:** Kevin Alejandro Vásquez Ramos

Sistema Integral de Gestión Educativa y Financiera para Colegios e Institutos Tecnológicos en Guatemala. Automatiza el control de morosidad, desbloqueo de **Pases de Evaluación con Código QR** y cálculo de **Actas Bimestrales MINEDUC** mediante **Triggers Transaccionales en MySQL**.
